# What is HoLoCards?
HoLoCards (Higher or lower on cards) is a simple guessing game about choosing 1 of two trading cards that you think is worth more. 
This came about because we all have a childhood love of these trading card games and collecting them.

# How did we make it?
A bulk of the development was done over the course of 24 hours at the HCCHack hackathon by our team: **[Nicolas](https://github.com/DSNicolasA)** , **[Jonathan]()** and **[Andrew](https://github.com/andrewblair390)**. It is made using the NextJS framework with react and tailwind CSS. The cards are all stored in our own personal database hosted by MongoDB.
